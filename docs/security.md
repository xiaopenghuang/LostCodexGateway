# 安全与隐私

## 设计原则

1. **Host Key 必须验证**：首次连接人工核对指纹；指纹变化阻断并告警；绝不使用 `StrictHostKeyChecking=no`。
2. **私钥零接触**：应用只保存私钥**路径字符串**，不读取、不复制、不导出；日志与诊断报告均不含私钥内容。密码类认证不支持（BatchMode），私钥口令由系统 ssh-agent 的标准交互处理。
3. **只监听回环**：SOCKS 与 HTTP CONNECT 桥接均只绑定 `127.0.0.1`；桥接拒绝非 CONNECT 方法与绝对 URI，不向局域网/公网开放。
4. **不碰服务器**：不自动改 `sshd_config`、防火墙、iptables；服务器上不装任何服务；现有 Docker/Nginx/CPA/SSH 业务不受影响。
5. **不提权**：基础模式全程普通用户权限；Mihomo TUN 的高级权限由 Mihomo/Clash Verge 官方组件处理，应用只显示影响与确认。
6. **不接管全局**：不写系统代理、不改路由表、不装网络驱动、不写用户/系统环境变量；代理注入只发生在「本工具启动的 CLI 子进程」与「用户确认导入的 Mihomo 规则片段」。
7. **不越界**：不保存 OpenAI OAuth、Cookie、API Key；不读取 Codex 认证目录；不做模型名映射、协议转译、OAuth 抓取。

## 日志策略

默认只记录：时间、组件、连接状态、错误类别、脱敏服务器地址与目标**域名**。
不记录：请求/响应正文、URL 完整路径、研究内容、模型 prompt、授权 Header。
诊断导出遵循同一规则。

## 桥接层边界（HTTP CONNECT → SOCKS5）

- 仅支持 CONNECT 语义（TCP 隧道），不解析 HTTPS 内容 → 无 TLS MITM、不安装根证书、不缓存。
- 限制：并发 64、请求头 16KB、握手 10s 超时。
- 日志仅目标域名与状态码。

## 威胁模型与已知边界

- 本地其他进程（含恶意进程）理论上也能连接 127.0.0.1 的 SOCKS/桥接端口使用隧道——这是所有本地代理工具的共同属性；本工具不做端口鉴权（v1 记录为已知限制）。
- 出口位置不改变账号地区/服务条款；不提供匿名化或绕过限制功能。
- SSH 连接本身直连服务器（不经过自身隧道），防止流量环路。
